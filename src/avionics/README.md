# Coludo avionics

The Rust flight firmware (Phase 6). It ports plan B, the MicroPython firmware in `src/glider`, frozen at tag
`micropython_plan_B_3`. One cargo workspace (`Cargo.toml`):

- `firmware/` -- the ESP32-P4 flight firmware (ESP-IDF, Rust std): the binary `avionics`, bench binaries in `src/bin/`.
- `crates/` -- portable crates, most named after the plan B module they port. Tested on the host; ESP-IDF only
  behind beacon's `esp` feature.
- `sitl/` -- the flight code on the host behind the UDP sim-link. `tools/hitl_host.py --sitl` flies it.
- `recorder/` -- the remote flight recorder on an ESP32-C6: the binary `flight_recorder`.
- `golden/` -- the fixture generator: runs plan B on CPython 3.12 and writes the JSON the crates are tested against.

## Build

Compile on cheeta, never on panda. Cheeta serves this tree over NFS at the same path. Use `+nightly-2026-10-05`
(cheeta's plain `nightly` is older: its rustc panics in esp-idf-svc) and an absolute `CARGO_TARGET_DIR`: a relative one
after `cd firmware` lands in `firmware/target/`, and panda's `target/` names panda-only tool paths.

    ssh cheeta
    export CARGO_TARGET_DIR=/home/ldm/src/dooing/coludo/src/avionics/target/cheeta
    cd /home/ldm/src/dooing/coludo/src/avionics
    cargo +nightly-2026-10-05 test                                  # host tests: crates/* and sitl
    (cd firmware && cargo +nightly-2026-10-05 build --release)      # the P4 firmware
    (cd recorder && cargo +nightly-2026-10-05 build --release)      # the C6 recorder

`firmware/` and `recorder/` carry their own target, build-std and ESP-IDF pin (v5.5.5) in `.cargo/config.toml`.

## Flash

On panda, where the boards sit on USB, in `src/avionics`:

    firmware/flash.sh target/cheeta/riscv32imafc-esp-espidf/release/avionics      # PORT=, default /dev/ttyACM0
    PORT=/dev/ttyACMn recorder/flash.sh target/cheeta/riscv32imac-esp-espidf/release/flight_recorder

`firmware/flash.sh` writes the bootloader, the partition table, otadata and `ota_0`, and blanks `ota_1`'s header.
The settings and the ring survive. The C6 goes on a direct USB port, its port found by its USB serial (see
`recorder/flash.sh`). OTA instead, from the repo root: `tools/ota.py --console /dev/ttyACM0 <ELF>` (USB console)
or `tools/ota.py <board> <ip> <ELF>` (Wi-Fi), with the board in SETTING and disarmed.
