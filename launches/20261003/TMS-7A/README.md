# TMS-7A — ASE wings, fins 0°

Half of the wing comparison. Flown against [TMS-7B](../TMS-7B/) on the same motor.

| | |
|---|---|
| glider | **183.0 g** (dual camera) |
| booster | **99.0 g** |
| motor | **E16** (82.5 g loaded) |
| liftoff | **364.5 g** |
| wings | **ASE** |
| fins | **fixed at 0°** |
| electronics | dual camera only — no telemetry board |

Deliberately carries no flight electronics: this slot answers a wing question, and putting the
instrumented board at risk to answer it is the wrong trade. The pair is 1.3 g apart in glider mass, so
what separates the two flights is the wing and the fin setting, not the build.

**Its result selects the fin angle** that [TMS-7C](../TMS-7C/) flies fixed.
