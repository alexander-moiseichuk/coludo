# TMS-7B — carbon wings, fins −5°

Half of the wing comparison. Flown against [TMS-7A](../TMS-7A/) on the same motor.

| | |
|---|---|
| glider | **184.3 g** (dual camera) |
| booster | **98.2 g** |
| motor | **E16** (82.5 g loaded) |
| liftoff | **365.0 g** |
| wings | **carbon** |
| fins | **fixed at −5°** |
| electronics | dual camera only — no telemetry board |

Two variables move between 7A and 7B — wing material and fin angle — so a difference in glide is not
attributable to one of them alone. That is accepted deliberately: the decision this pair feeds is
"which configuration do we fly", not "which of the two changes caused it".
