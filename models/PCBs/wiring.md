# Wiring Layout for Main Board
For context all of the wiring will be interpreted with a reference frame of looking at the board from the top and all of the letters are facing the correct side
ie. they are able to be read normally. 

## Top of Main Board
- Pin 1: TX1: Leftmost pin 
- Pin 2: TX2
- Pin 3: RX2
- Pin 4: Laser Control 
- Pin 5: SCL   
- Pin 6: SDA
- Pin 7: VCC: Sqare Pin    
- Pin 8: GND: Rightmost Pin

## Bottom of Main Board
- Pin 1: Left Servo: Leftmost Pin
- Pin 2: Yaw Servo
- Pin 3: Right Servo
- Pin 4: Alert 
- Pin 5: SDA   
- Pin 6: SCL
- Pin 7: VCC: Sqare Pin    
- Pin 8: GND: Rightmost Pin

# Wiring Layout for Power Board
Same as on bottom of main board

- Pin 2: Yaw Servo
- Pin 3: Right Servo
- Pin 4: Alert 
- Pin 5: SDA   
- Pin 6: SCL
- Pin 7: VCC: Sqare Pin
